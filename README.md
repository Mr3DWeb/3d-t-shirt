## 3D T-Shirt Painting 

### 🎨 Paint & Customize : 
- Change T-shirt color
- Change Skin color (huamn)
- Adjust Brush color & size

###  🏃‍♂️ See It in Action
- Run the animation
- Show / Hide human model

### 🛠 Full Control : 
- Zoom In & Zoom Out 🔍
- Lock, Delete
- Undo, Redo ↩️

#### And finally, you can take a snapshot of what you created. 📸


## 🛠️ Tech Stack

*   **Core:** [Three.js](https://threejs.org/)
*   **Language:** Vanilla JavaScript (ES6+)
*   **Styling:** CSS3
*   **Build Tool:** Vite
